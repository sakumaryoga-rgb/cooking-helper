# v1.7.0 リリース手順(Phase 6: UI 刷新)

DB の変更はない(Migration なし)。承認後に PR をマージして本番デプロイし、`v1.7.0` タグを付ける。

## 変更(リニューアル設計書 4 章・9 章)

- 下部タブを「ホーム・レシピ・冷蔵庫・設定」の4つにした。旧「グループ」は設定へ(/group は /settings に転送)。
- ホーム: 「今すぐ作れる」「代替で作れる」の2段と、期限が3日以内の食材。不足のあるレシピは出さない。
- レシピ一覧: 「すべて・作れる・代替で作れる・不足あり」で絞り込み、料理名・材料・出典で検索。不足の行に不足量。
- レシピ詳細: 必要量・在庫・不足量、代替候補を行の中で選ぶ(使わないも選べる)、人数の増減(取り込んだレシピ)、
  「元のレシピを見る」「これを作る」を画面下部に固定。
- 調理の確定: 下から出るシートで、使った量・代替・不足を1画面で確認。確定後に「取り消す」を数秒表示。
  履歴からの取り消しは24時間以内の記録だけを表示。
- 冷蔵庫: 「すべて・期限が近い・カテゴリ」で絞り込み。
- 設定: 家族グループ、招待、メンバー、アカウント(この端末でサインアウト)、使わない代替、プラン(枠のみ)、規約(準備中)、バージョン。
- ブランド色: 黄色 #FED712 をアクセント(文字は濃い茶色)、トマトの赤を期限・不足の警告色、クリームの白を背景。
- iPhone の上下の安全領域に合わせた余白。

設計書にあるもののうち、DB の変更が必要なロットの「保存場所」、Phase 7 の規約への同意・課金は含めない。

## iPhone での確認

1. 「更新する」でバージョン 1.7.0。下部タブが4つで、画面の上下が安全領域に収まる。
2. ホームに作れるレシピと期限の近い食材が出る。期限の食材を押すと冷蔵庫が「期限が近い」で開く。
3. レシピ詳細で人数・代替を変えられ、「これを作る」で下からシートが出る。確定後の「取り消す」で戻る。
4. 設定で招待リンクの発行、メンバー、サインアウトが使える。
