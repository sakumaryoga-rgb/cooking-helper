## 方針の変更

「すべてを確かめてから保存」から「安全に保存できるものは保存し、必要な確認だけ必要なときに」へ。

- 分量: 食材の単位に直せる根拠(g・ml・大さじ、同じ単位)があるときだけ数にする。「1パック」「少々」「1/2丁」「150〜200g」は
  元の表記のまま保存する(換算を推測しない)。在庫と数で比べられない材料は「分量を確認」とし、「作れる」と断定しない
  (少々・適量は在庫があれば足りているとみなす)。調理のときは、使った量を入れた材料だけ在庫から引き、
  「次から 1パック = 200g として覚える」を選ぶと家庭ごとに覚えて、以後は数で判定する。
- 状態・加工: 属性(冷凍・皮なし・すりおろし・カット・ホール・ゆで など)は同じ食材に自動で結び付け、状態を注記に残す。
  別の食材(干し・乾燥・ドライ・無塩・減塩・甘塩・チューブ・缶詰・水煮 など)は元の食材にまとめず、その名前の食材
  (なければ家庭の食材マスタに登録)にする。例: 干ししいたけ / しいたけ、無塩バター / バター。
- 未登録の食材: 似た食材がなければ家庭の食材マスタに自動で登録する(在庫は0のまま、共通の食材マスタには追加しない)。
- 確認待ち: 部分一致や候補が複数(豆腐 → 木綿 / 絹)のときだけ。レシピの保存は妨げず、詳細画面で1タップで選べる。
  選んだ表記は家庭の別名として覚える。

## 在庫から引かない材料の明示と、換算の範囲

- 調理の確定画面の上に「次の材料は在庫から引きません」と、分量が決まっていない材料・どの食材か決まっていない材料を出す。
- 換算は「冷蔵庫の食材の行 × 単位」ごとで、完全に一致するときだけ使う(別の食材・別の単位・ほかの家の行・幅のある分量には使わない)。
  人数を変えたら換算した量も変える。包装量が商品で違うことがあるので、換算で計算した材料は確定画面で
  「覚えた『1パック = 200g』で計算しました。商品で量が違うときは直してください」と示し、量はその場で直せる
  (覚え直すと上書き)。
