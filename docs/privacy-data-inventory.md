# 収集しているデータの一覧(プライバシーポリシーの元資料)

一般公開時のプライバシーポリシーは、この一覧と一致させる。項目を増やすときは、先にこの一覧と
グループ画面の説明文(`src/lib/telemetry/notice.js`)を更新する。

## アプリの機能として保存するデータ

| データ | 保存先 | 目的 |
| --- | --- | --- |
| メールアドレス | Supabase Auth | ログイン(メールリンク) |
| グループ名、招待コード、所属 | groups、group_members | 家族での共有 |
| 食材、在庫、賞味期限の目安 | ingredients、ingredient_batches | 冷蔵庫の管理 |
| レシピ(名前、材料、参照先 URL) | recipes、recipe_ingredients | 作れる料理の判定 |

## 品質改善のために記録するデータ(v1.1.0 から)

| 項目 | page_views | client_errors | 内容 |
| --- | --- | --- | --- |
| 日時 | ○ | ○ | 記録した時刻(サーバーが決める) |
| ユーザー ID | ○ | ○ | 内部の ID。メールアドレスは含まない |
| グループ ID | ○ | ○ | 所属グループの内部 ID |
| アプリのバージョン | ○ | ○ | 例: 1.1.0 |
| 画面 | ○ | ○ | /fridge、/recipes/:id など。レシピの ID やクエリは含まない |
| エラーの種類と文面 | | ○ | 伏せ字にしたもの。500文字まで |
| エラーの発生箇所 | | ○ | アプリのファイル名と行番号。伏せ字にしたもの。2000文字まで |
| エラーの指紋 | | ○ | 同じエラーをまとめるための8桁の値 |

**記録しないもの**: 料理・食材・レシピの名前や内容、レシピの参照先 URL、入力した文字、メールアドレス、
招待コード、ログインのトークン、IP アドレス、端末の機種、位置情報、閲覧時間やスクロール。

伏せ字にする対象(`src/lib/telemetry/sanitize.js`): URL(アプリ自身のファイル以外)、JWT と Bearer、
key=value 形式のトークン、メールアドレス、UUID、招待コード、32文字以上のランダム文字列、
日本語・空白を含む引用や30文字を超える引用。

**家族向けの説明文**との対応: 「画面の利用状況」はページビュー、「エラー情報」は client_errors。
「料理の内容や入力した情報は収集しません」は、上の「記録しないもの」と伏せ字で担保する。
エラーの文面に入力内容が紛れ込む可能性はゼロではないため、伏せ字の対象は見つけ次第増やす。

- 保存期間: 90日(自動削除)。
- 閲覧できる人: 運営者のみ(Supabase の SQL Editor)。家族を含むアプリの利用者は読めない。
- 第三者への提供: なし。外部の解析サービスは使っていない。
- 削除の依頼: ユーザー ID 単位で削除できる(`docs/telemetry.md`)。
