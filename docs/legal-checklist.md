# 規約・プライバシーポリシー

v1.25.0 で正式版にした(版 2026-10-11)。文面は `src/routes/Legal.jsx`、確定項目は `src/lib/legal.js` の `LEGAL_INFO`。

| 項目 | 内容 |
| --- | --- |
| 運営者 | 個人開発(ryogasakuma) |
| 住所 | 請求があれば遅滞なく開示します |
| 窓口 | アプリ内の「お問い合わせ」フォーム(メールアドレスは載せない) |
| 責任の制限 | BASKETBALL STATS と同じ(金額の上限なし、軽過失は通常かつ直接の損害、消費者契約法の範囲内) |
| 合意管轄 | 運営者の所在地を管轄する日本の裁判所 |
| データの保存地域 | 日本(東京)(Supabase) |
| 施行日 | 2026-10-11 |

## 同意の流れ(BASKETBALL STATS と同じ)

- 初めて開いたとき(ログインの前)に同意画面を出し、同意を端末(localStorage の `cookdoor:consent`)に記録する。
- ログインしたら、同意の記録を `user_consents` にも残す。残せなくても利用は止めない。
- 改定するときは `src/lib/legal.js` の `VERSION` を上げる。全員に「改定しました」の同意画面が出る。
- 収集項目・保存期間を変えたら、プライバシーポリシーの文面も合わせて直す。
