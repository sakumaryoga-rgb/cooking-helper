# 分量の換算マスタ(migration 026)の網羅状況

共通の食材マスタ(`ingredient_catalog` の group_id が null の品目)全件と、`supabase/seed/unit_conversions.csv` の照合結果。
`node scripts/build-unit-conversion-seed.mjs` で CSV から migration 026 の投入部分を作る。数値は公開資料の「目安」で、在庫の自動の差し引きには使わない。

## 集計

在庫の単位と実際に換算できるかで分けた。「目安の行がある」だけでは数えない。

換算できるかの判定: 目安の換算先(g)が在庫の単位(g・kg)と同じ次元か、目安の単位が在庫の単位と同じ(逆向きに g → 本 で使う)か、
目安の単位が在庫の単位と同じ次元(大さじ ⇔ ml)のとき。単位の名前が違うもの(玉と個、本と個、片とかけ)は同じとみなさない。
