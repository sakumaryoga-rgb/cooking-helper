# v1.15.0 リリース手順(レシピの削除・作り方の手順入力・食材の整合性・表記揺れ)

DB の変更なし(Migration なし)。既存の RLS(選んでいる家のレシピ・家庭の別名だけ書き込める)のまま動く。
011 と 017 は適用しない。

## 変更

- レシピの削除: 詳細の「編集・削除」→ 編集画面の下の「このレシピを削除」→ 確認ダイアログ。
  材料の行も消える。冷蔵庫の食材と作った記録は残り、作った記録の取り消しもできる(DB テストで確認)。
- 作り方: 番号付きの手順の一覧で入力(手順の追加・並べ替え・削除)。保存の形は従来どおり1手順1行。
- 冷蔵庫とレシピの食材の整合性:
  - 食材を選ぶ画面の「登録済みの食材」をなくし、冷蔵庫にある食材もカテゴリの中に「冷蔵庫に 3個」と出す。
    選ぶと冷蔵庫のその行を使う(同じ食材の行を二重に作らない)。レシピで使っている材料は選べない。
  - 食材マスタに結び付いていない以前の冷蔵庫の行は「その他」に出す。カテゴリに「その他」を追加。
  - レシピから取り込んだ、食材マスタにない食材は、名前からカテゴリを推定して家庭の品目に登録し、冷蔵庫の行と結び付ける
    (以前は冷蔵庫の行だけ作っていたため、冷蔵庫の「食材を選択」のカテゴリに出なかった)。
  - 「リストにない食材を追加」で、表記だけ違う同じ食材(じゃが芋 / じゃがいも)が冷蔵庫にあれば、それを使う。
- 表記揺れ:
  - 別名辞書(ingredient_aliases)に加えて、漢字とかな(芋・葱・人参・玉葱・挽き など)、「新」「国産」「冷凍」などの接頭語、
    「(中)」「大」などの大きさをそろえて突き合わせる。ジャガイモ / じゃが芋 / 馬鈴薯 / 新じゃがいも / じゃがいも(中) は
    すべて「じゃがいも」になる。
  - 取り込みの確認画面で、材料を「⇄」で正しい食材に付け替えると、取り込んだときの表記をこの家の別名として覚え、
    次に同じ表記のレシピを取り込むと自動でその食材になる。

## 切り戻し

v1.14.0 に Instant Rollback できる。DB の変更はない。v1.15.0 で覚えた家庭の別名と、家庭の食材マスタに登録された品目は残るが、
v1.14.0 でもそのまま使える(既存の仕組みのデータ)。
