# ログイン状態が消えた事象の調査(2026-10-08)

## 事象

2026-10-08 20:32(日本時間)、v1.0.1 の確認に使った Chrome で cookdoor.app を開くと
ログイン画面になった。cookdoor.app の localStorage は空で、Supabase のセッションのキーもなかった。
同じ Chrome では 20:16 ごろまでログインしたまま操作できていた(v1.0.0 の確認時)。
その時点のコードは v1.0.0(Service Worker の更新前)。

## 調べたこと

| 対象 | 結果 |
| --- | --- |
| `useSession` | `getSession()` と `onAuthStateChange` を使うだけ。セッションを消す処理はない |
| `supabaseClient.js` | supabase-js 2.112.3 の既定値(persistSession、autoRefreshToken、localStorage)。本番ビルドでは本番の接続先 |
| localStorage の使用箇所 | アプリは招待コード(`pendingInviteCode`)だけ。セッションは supabase-js が管理する |
| ログアウトを呼ぶ箇所 | ヘッダーの「サインアウト」ボタンだけ(`Layout.jsx`) |
| Service Worker | precache と更新だけ。localStorage と Cookie には触れない。`cleanupOutdatedCaches` が消すのは Cache Storage だけ |
| PWA 更新 | 「更新する」はページの再読み込みだけ。v0.0.0→v1.0.0 と v1.0.0→v1.0.1 の更新後もログイン状態は残った |
| Supabase のセッション設定 | 期限なし、無操作の期限なし、同時ログインの制限なし。アクセストークン 3600 秒。リフレッシュトークンの再利用検知は有効 |

## Supabase の認証ログ(時刻と種類だけを抽出。ユーザー ID とトークンは見ていない)

| 時刻(日本時間) | 出来事 | アカウント |
| --- | --- | --- |
| 19:44:34 | トークンの更新(ログイン扱い) | A |
| 20:17:33 | **ログアウト(POST /logout)** | A |
| 20:20:03 | 存在しないリフレッシュトークンでの更新(refresh_token_not_found) | 不明(ID を持たない) |

アカウントの同一性は、ID のハッシュを丸めた値の一致だけで判断した。

## 分かったこと

1. 20:17:33 に、アカウント A で「サインアウト」が実行された。アプリでログアウトを呼ぶのはこのボタンだけ。
2. supabase-js の `signOut()` は既定で `scope: 'global'`。**同じアカウントの全端末のセッションが失効する。**
3. 失効した端末は、次のトークン更新で refresh_token_not_found を受け取り、supabase-js が
   localStorage のセッションを消す。20:20:03 の記録はこれと一致する。
4. Service Worker、PWA の更新、v1.0.1 の変更がセッションを消した形跡はない。

## 分かっていないこと

- アカウント A が確認に使った Chrome のアカウントと同じか(ID を見ていないため)。
- 20:17:33 のサインアウトが、どの端末で誰の操作によるものか。Claude の操作ではサインアウトのボタンを押していない。

## 再現条件(推定)

1. 同じアカウントで2つの端末(または Safari とホーム画面のアプリ)にログインする。
2. 片方で「サインアウト」を押す。
3. もう片方は、アクセストークンの期限(最長1時間)が来るか、再読み込みしたときにログアウト状態になる。

## 対応

原因を断定できないため、コードは変えていない。次を提案する(承認後に実施)。

- サインアウトを `signOut({ scope: 'local' })` にし、押した端末だけをログアウトさせる。
  家族が同じアカウントを複数の端末で使う運用と合う。
- iPhone では、Safari とホーム画面のアプリはログイン状態を共有しない。Safari で「サインアウト」を押すと、
  global の場合はホーム画面のアプリも次の更新でログアウトする。

## 確認してほしいこと

- 2026-10-08 20:17 ごろに、どこかの端末で「サインアウト」を押したか。
- 確認用の Chrome と同じアカウントを、iPhone でも使っているか。
