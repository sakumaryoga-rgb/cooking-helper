# v1.17.0 リリース手順(取り込み対応サイトの拡大・手順ごとの材料・UI)

本番 SQL Editor で実行するのは `supabase/migrations/025_recipe_steps.sql` だけ。**025 を適用してから v1.17.0 をデプロイする**。
011 と 017 は適用しない。025 は何度実行しても同じ結果になる。

## 既存データへの影響

なし。recipes に steps(手順ごとの材料と量)の列を追加し、update_recipe に省略できる引数 p_steps を足す。
既存のレシピ・材料・作り方は変わらない。update_recipe は8引数の1つに置き換わるが、v1.16.0 の7引数の呼び出しもそのまま動く。

## 古いアプリ

`minSupportedVersion` を 1.17.0 にした。v1.16.0 でオリジナルレシピを編集すると、手順ごとの材料の記録が更新されず、作り方の文と食い違うため。

## 変更

- 取り込みに対応するサイトを 3 → 11 に拡大(docs/recipe-sites.md)。共通の JSON-LD の読み取りのまま、材料の行の書き方
  (「…」の区切り、グループの記号「A」、「ɡ」)を共通の処理で読めるようにした。対応しない URL は、URL を残して手動で登録できる。
- レシピの追加: URL の取り込みを主役にした画面(使いかた・対応サイトの一覧・貼り付けボタン)。対応サイトは名前とイメージカラーで示し、
  公式ロゴは使わない。提携していないことを明記。
- オリジナルレシピ: 手順ごとに、そのレシピの材料から使うものと量を選べる(任意)。手順の量は目安で、在庫はレシピの材料の分量で
  引く(二重に減らない)。手順の合計とレシピの分量が違えば、画面で知らせる(自動で直さない)。
- URL から取り込んだレシピ: 作り方は入力しない。詳細に「元のレシピで作り方を見る」。保存済みの作り方は消さない。
- 戻る導線: 詳細・追加画面に「レシピ一覧」、保存の直後に「レシピ帳に保存しました」と一覧への導線。編集の保存・やめるは履歴を1つ戻る
  (以前は詳細画面を二重に積み、戻る操作で同じ画面に戻っていた)。
- 設定: 本人のメールアドレスを全文表示(家族には表示しない。DB には保存しない)。プランは「いま使える機能(無料)」と「今後の予定(準備中)」
  を分け、申し込みのボタンは出さない。

## 切り戻し

アプリは v1.16.0 に Instant Rollback できる。025 は残してよい(v1.16.0 は steps を使わない)。
