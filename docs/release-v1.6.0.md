# v1.6.0 リリース手順(Phase 5: 冷蔵庫と期限管理)

承認後に行う。Migration 011 とは独立している(011 はまだ適用しない)。

## 変更

- **ロットの期限**: 在庫ロットごとに賞味期限か消費期限(どちらか一方、任意)を入れられる。DATE で保存。
  入れていないロットは、購入日 + 食材マスタの日持ち日数(なければ7日)を「推定」期限として表示する。
- **冷蔵庫画面**: 各食材の「期限を入れて増やす」(カレンダーの印)と、「追加」で食材を選んだ直後に、量・購入日・期限の種類と日付を入れられる。
  食材の期限は、在庫のあるロットのうち最も早い期限。「消費期限 10/12・あと2日」「推定 10/12・期限切れ」「期限未設定」のように種類と状態を出し、
  期限切れ(赤)・2日以内(黄)・未設定を区別する。期限の近い順に並べ、未設定は後ろ。期限切れでも在庫は消さない。
  食材をタップすると、購入日・期限の違うロットを分けて表示する。在庫なしの食材の折りたたみは従来どおり。
- **消費順を FEFO に統一**: 消費期限 → 賞味期限 → 推定期限のうち使える期限の早いロットから。同じ期限なら購入日の古い順、
  期限のないロット(購入日も期限もない)は最後。数量の「−」・作った(新旧とも)で同じ関数を使う。
  **これまでの「日付なしロットを先に消費」から変わる。**
- **取り消し**: 調理の記録にロットの購入日と期限を残し、取り消しで期限ごと元のロットに戻す。

## 動作確認(iPhone)

1. 「更新する」でバージョン 1.6.0。冷蔵庫・レシピが普段どおり。
2. 牛乳などでカレンダーの印 → 消費期限を明日にして増やす。一覧に「消費期限 ○/○・あと1日」(黄)が出て、上の方に並ぶ。
3. 食材をタップすると、購入日・期限ごとのロットが出る。
4. その食材を使うレシピで「作った」→「取り消す」。ロットと期限が元に戻る。
